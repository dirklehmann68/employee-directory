===========
Quick Start
===========

This chapter explains how to set up your first
employee directory in TYPO3.

Create a storage folder
=======================

1. Open the TYPO3 backend.
2. Create a new folder in the page tree.
3. Use this folder to store your employee records,
   departments, and job functions.

Create departments and job functions
====================================

1. Open the List module.
2. Select the storage folder.
3. Create the required department records.
4. Create the required job function records.

Create employees
================

1. Create a new employee record in the storage folder.
2. Enter the employee's name and contact details.
3. Assign a department and a job function.
4. Optionally add a profile image and further details.
5. Save the record.

Add the plugin
==============

1. Open the page where the directory should appear.
2. Create a new content element.
3. Select an Employee Directory plugin.
4. Configure the record storage location.
5. Save the content element.

Open the page in the frontend to view your
employee directory.
