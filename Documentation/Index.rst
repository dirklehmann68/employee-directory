==================
Employee Directory
==================

Employee Directory is a TYPO3 extension for displaying
and filtering employee profiles.

It provides searchable employee cards, A-Z filtering,
department and job function filters, and optional
employee detail views.

The extension supports TYPO3 14 LTS.
