============
Introduction
============

Employee Directory is a TYPO3 extension for managing
and displaying employee profiles on a website.

Features
========

* Employee cards with profile images and contact details
* Full-text search for employee records
* Alphabetical A-Z filtering
* Filtering by department and job function
* Optional employee detail pages
* Three plugin configurations
* German and English interface translations
* Standalone CSS and Bootstrap styling options

Requirements
============

* TYPO3 14.3 or later
* PHP version compatible with TYPO3 14
